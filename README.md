# plz

PLZ is a PL/M inspired compiler suite for the Z80 CPU implemented in Go language.


# Credits

PLZ uses github.com/koron-go/z80 as the z80 emulator for testing, under the MIT
License.

The z80 assembler is based on github.com/paulhankin/z80asm
and was imported into this project for modifications under the MIT license.

Thanks to you all!
